# Modelagem 3D — Área de Serviço

Simulação 3D interativa (Three.js) da área de serviço de casa, para visualizar se
os novos equipamentos cabem no espaço.

## Como abrir
- Abrir o `index.html` no navegador (precisa de internet para carregar o Three.js).
- Para ter um link e mandar pelo WhatsApp: em **Settings → Pages** do repositório, escolher
  a branch deste projeto e a pasta `/ (root)`. O GitHub mostra o endereço da página.

## Como corrigir uma medida
Todas as medidas ficam no objeto `M`, no começo do script do `index.html`, em centímetros.
Os valores marcados com `(E)` foram estimados pelas fotos.
